# Officials' Dashboard

The dashboard gives authorized agriculture officials a regional view of reported crop threats and response needs. It reports observed patterns and recommended action; it does not claim root-cause analysis.

## Round 1 journey

1. Open the India overview and select Maharashtra.
2. Drill down to a district.
3. Inspect green, yellow, or red severity with a textual label.
4. Review crop, probable issue, report count, confidence, and trend.
5. View a generated response recommendation and its supporting facts.
6. Open a simulated lab referral or monthly report.

## Required views

- National/state/district severity map
- District summary and recent trend
- Crop and issue breakdown
- Case/referral queue
- Recommended actions with provenance
- Monthly report preview and export
- Data freshness, model version, and demo-data indicators

## Severity contract

- **Green / low:** monitor; insufficient evidence of a concentrated outbreak.
- **Yellow / moderate:** investigate and consider field sampling.
- **Red / high:** prioritize expert review and coordinated response.

Exact thresholds belong in a versioned policy configuration and require domain-expert approval before any pilot.
