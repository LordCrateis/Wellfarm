# Farmer App Source

Place the farmer client source here when the frontend framework is selected.

Suggested feature boundaries:

```text
features/
  onboarding/
  scan/
  diagnosis/
  advice/
  referrals/
  settings/
lib/
  api/
  i18n/
  accessibility/
```

Keep network contracts in `packages/contracts` rather than duplicating response types inside the app.
