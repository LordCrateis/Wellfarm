# Farmer App

The farmer-facing experience provides crop scanning, approximate-location context, live weather, readable model results, and a private scan history.

## Core journey

1. Upload or photograph an affected plant.
2. Allow approximate location or continue without it.
3. Select crop details and visible symptoms.
4. Receive ranked indications with confidence and limitations.
5. Save the record to the fieldbook.

The app does not submit cases, create referrals, contact third parties, or prescribe chemical treatment.
